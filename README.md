# 🎓 UniMate – Your University Companion

**UniMate** is an Android-based university companion application designed to help students manage their academic activities in one place.

It provides a simple and user-friendly platform for organizing class routines, assignments, study notes, exam schedules, daily tasks, and academic performance.

## ✨ Features

- 📅 **Class Routine:** Add, view, edit, and delete class schedules.
- 📝 **Assignment Manager:** Organize and track academic assignments.
- 📚 **Study Notes:** Create, manage, and update study notes.
- 🗓️ **Exam Schedule:** Keep track of upcoming examinations.
- ✅ **To-Do List:** Manage daily tasks and mark completed activities.
- 🎯 **CGPA Calculator:** Calculate CGPA based on course credits and grades.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **UI Design:** XML
- **Database:** SQLite
- **Development Environment:** Android Studio
- **Version Control:** Git & GitHub
